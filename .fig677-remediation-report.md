## Finding-to-fix and regression map

1. **Resumable Restate starts.** Post-registration workflow-submission and
   external-reference failures now retain staging inputs; cleanup happens only
   on authoritative abandonment. Deterministic injection covers registration,
   submission, external-ref failure, and recovery in
   `restate_start_failures_preserve_inputs_for_exact_recovery`.
2. **Production dependency wiring.** `LashCore` retains the host process-engine
   registry separately from session-scoped engines and passes the exact bound
   environment store/engines through facade, tool-intent, trigger, and session
   start paths. `host_owned_processes_run_without_application_session` and
   `session_trigger_process_visibility_conformance` exercise real controllers.
3. **Public replay.** Public session/facade starts carry the environment spec
   into the replayable effect and no longer republish through a retired staging
   owner. Existing process ownership is discovered/transferred idempotently.
   `process_start_and_cancel_emit_typed_observation_events` and the host-owned
   process test both repeat public starts after staging retirement.
4. **Recoverable process-prune cleanup.** `ProcessArtifactCleanup` is recorded
   transactionally with prune/tombstone state and acknowledged only after exact
   environment and engine-family release. Trait decorators forward the new
   APIs. In-memory, SQLite-reopen, PostgreSQL-reopen, and facade fault-injection
   tests preserve a shared owner and retry after each artifact family fails.
5. **Complete execution-owner cleanup.** Existing
   `effect_scope_retirements` rows now carry `artifact_cleanup_completed`.
   Session deletion plus immediate/deferred operation retirement enumerate
   pending scopes, permanently retire each configured artifact store, then ack.
   Immediate facade errors are returned. SQLite reopen injection fails once at
   each environment/module store; PostgreSQL/SQLite effect-journal tests prove
   pending/ack state, and the seven-test runtime-operation suite proves facade
   and deferred-sweep behavior.
6. **Real slow-writer evidence.** `ArtifactPublicationPause` is consumed inside
   memory, SQLite, and PostgreSQL publication before the serialized mutation;
   conformance starts a writer, observes the pause, commits retirement, resumes
   it, and requires typed refusal with no resurrected bytes/edge.
7. **PostgreSQL artifact serialization.** Every publish, retain, transfer,
   release, and retirement takes a stable advisory lock keyed by
   `(namespace, artifact_ref)` after ordered owner locks. Real PostgreSQL 16
   tests deterministically hold that exact key and prove a committed B owner
   survives A release, concurrent final releases remove bytes, and retirement
   fences a late publisher. The first race waits until `pg_stat_activity`
   proves release reached its serialization point, eliminating scheduler
   false-greens.
8. **Cross-store retirement recovery.** The same durable pending/ack evidence
   from item 5 survives reopen until every store succeeds. The recovery test
   additionally proves the authoritative journal fence immediately rejects a
   late runtime effect, and completed cleanup rejects late environment and
   module publication.
