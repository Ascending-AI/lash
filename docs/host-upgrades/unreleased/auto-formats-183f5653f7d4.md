# r61 P1: linked declarations for workflow source

Workflow printing and exported-source reading use immutable linked package
metadata for types, methods and callable async/rest flags. `HostArtifacts::print_workflow`
loads that metadata from retained Links; its host signature is unchanged.

| Old contract | New contract and host action | Missed-change diagnostic |
| --- | --- | --- |
| `lash::typescript::{print, read}`, `lash::python::{print, read}`, `lash::dialect::Printer::print` and `lash::dialect::ReadSource` take only a library for source context | Pass the linked `Namespaces` after the library argument. `lash::dialect::regions::namespaces` takes the declarations after the document. | Rust argument-count/type error; missing declarations refuse as `NamespaceRefusal::MissingDeclaration`. |
| `lash::vm::WorkerService::print` and `read_exported` reconstruct callable declarations from imports | Pass `Namespaces` after the document/base argument. `Print` and `Read` service requests carry these declarations. | Rust argument-count error or worker protocol refusal. |
| Worker protocol 12 | Deploy protocol 13 host and worker binaries together and restart the worker pool. The version guard rejects mismatched workers before guest work. | Worker protocol version refusal. |

adds `MissingDeclaration` and `DeclarationConflict`; exhaustive matches need
these cases. The saved Document, workflow and parked VM formats do not change.
