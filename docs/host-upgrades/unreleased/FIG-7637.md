# FIG-7637: Guest JSON boundaries

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| Broker, console, language formatters and diagnostic projections had independent JSON writers. Copying TS arguments also normalized values. | One kernel-library encoder owns all guest JSON emission. Undefined object members are omitted, null stays null, and undefined or sparse array slots become null. Guest copying retains undefined keys and holes. Host function transport keeps the documented canonical `$lash_function` shape and reserved-key escaping; text omits functions or emits null in arrays. Unsupported values name their boundary and path. | This commit, FIG-7637 | Optional undefined fields previously failed with bare `not_data`. |
| `datum_to_json(value)` and `datum_to_json_with_limits(value, limits)` returned `NotJson`, with unsupported kinds described by `JsonlessKind`. | Supply `JsonModel` and a boundary context: `datum_to_json(value, model, context)` or `datum_to_json_with_limits(value, model, context, limits)`. Errors are `NativeError`; `NotJson` and `JsonlessKind` are removed. No new feature or configuration opt-in is required. | This commit, FIG-7637 | Existing callers get a signature or unresolved-import compiler error. |
| Python json.dumps had fast and fallback writers. | Callback preparation uses the same encoder, including formatting, scalar mapping keys, NaN policy and path errors. Python tuples remain JSON arrays, including empty tuples. | This commit, FIG-7637 | Fast and callback formatting could disagree or lose path diagnostics. |
| Frozen argument projections used v1 identities, and json.encode used a six-field style. | Projection identities are v2 and record the source value model. json.encode native version 2 uses the documented nine-field style. Rebuild/re-admit affected definitions using the normal native adoption process; no old decoder or projection alias is installed. | This commit, FIG-7637 | An old argument projection or native identity is refused explicitly. |
