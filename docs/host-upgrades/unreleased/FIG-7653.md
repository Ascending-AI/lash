# FIG-7653: Deferral uses the admission-pinned wait

| --- | --- | --- | --- |
| Documentation required a provider to call `AttemptContext::completion_key()` before returning `Pending`. | An admission-pinned completion wait is sufficient. Read its key only when delivering it to an external resolver; a host can instead obtain it through `Completions::parked` after parking. No new opt-in or format reset. | This commit, FIG-7653 | `pending_tool_missing_completion_key` now describes absent admission-pinned wait availability, not failure to call the accessor. |
| Direct consumers of the internal process-controls crate called `execute_process_await_tool_call(context, args)`. | Call `execute_process_await_tool_call(args)`. The helper declares a process-terminal resolver; dispatch enforces wait availability. No new opt-in. | This commit, FIG-7653 | Compiler error for the removed context argument. |
