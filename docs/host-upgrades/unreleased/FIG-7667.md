# FIG-7667: Remove retired island execution diagnostics

FIG-7694 supersedes its execution-strategy row.

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `KernelMachine::{count_execution, take_execution_census}` and `perf_witness::execution::{Census, Owner, Reason}` | Remove collection of the retired island execution census. The bytecode core has no physical-owner census either. No opt-in is required. | This commit, FIG-7667 | Removed methods and module do not compile. |
| `kernel_internals::{call_islands, register_work, RegisterWork, verify_bulk_source_rooms}` and `perf_witness::{register_work, RegisterWork}` | Remove island-plan and register-work probes from first-party tooling. No opt-in is required. | This commit, FIG-7667 | Removed imports and functions do not compile. |
| `testing::{Family, FamilyCounts, FamilyExit, begin_family_witnesses, take_family_witnesses, take_text_operation_publications, take_packet_counts}` | Remove island-only witnesses. Value, charge, ownership and checkpoint comparisons remain available. No opt-in is required. | This commit, FIG-7667 | Removed imports and functions do not compile. |
| `testing::ExecutionStrategy::GenericPackets` | Superseded: FIG-7694 removes `testing::ExecutionStrategy` with every variant; see its entry. | This commit, FIG-7667 | The removed enum does not compile. |
| `lash_vm_worker::core_support::compare::Measurement::execution_census` and compare receipt row `execution_census` | The worker measurement and new compare receipts omit the retired diagnostic. Update diagnostic consumers; historical receipts retain their original fields. No opt-in is required. | This commit, FIG-7667 | Field access does not compile; new JSON has no `execution_census`. |

Checkpoint and page formats are unchanged. No store reset is required.
