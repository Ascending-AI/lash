# FIG-7517: Land allocates pre-1.0 format witnesses

The existing integer stamps remain the reader/writer contract because they
also appear in compact binary headers, typed plugin versions and SQL schema
stamps. Replacing them with fingerprints would change these contracts across
all readers. Instead, land allocates each next integer after rebase, and
regenerates its allocation if a push loses a race. Authored branches need no
witness edits, and cannot collide over allocating the next integer.

`scripts/check_version_bumps.py::STRICT_VERSION_BUMPS` is the single 1.0
switch. Before the cut, changes require reset rather than migration evidence.
After the cut, automatic allocation stops and the existing explicit bump and
migrate/drain/coexist evidence checks apply. Kernel semantic and package
versions do not change.

Sources: [allocation](../../../scripts/apply_format_witnesses.py),
[landing](../../../scripts/land),
[preflight](../../../crates/lash/src/preflight/extract.rs).

`DurableFormat::HostStoredShapes` reports the new
`lash::formats::HOST_STORED_SCHEMA_VERSION` witness, initially 1. Hosts storing
canonical transcript/call/verdict records, process projections, workflow views,
execution overlays, sidecars, authoring data or package records retain this
witness with their product rows. A missing or changed witness requires recreation
or a source-snapshot compatibility review before reading those rows. Lash's
preflight reports that host-owned rows are not scanned.

The [host storage inventory](../../agents/host-stored-shapes.md) lists the roots
and documentation authorities, including the existing checkpoint and backend
coverage. The cc0e5b332f regression is detected by both checkpoint and host-storage
witnesses. Trace schema 37, existing stored encodings and kernel semantics remain
unchanged. No feature or configuration opt-in is needed.

Before the cut, `TRACE_SCHEMA_VERSION` delegates reset detection to the
host-storage witness. The gate requires that witness to cover the complete
trace preimage and advance when it changes. Trace schema filenames remain at
37. Strict mode ignores this pre-cut relation and requires the original
explicit trace bump and upgrade evidence.
