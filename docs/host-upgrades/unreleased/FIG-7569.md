Failure JSON changes from `{"kind":"host","exec_failure":"executor_unavailable","message":"unavailable"}` to `{"cause":{"type":"exec_failure","reason":"executor_unavailable"},"message":"unavailable"}`. Other cause variants retain optional accompanying `bound`; a primary `bound` cause requires its `fact`. Unclassified causes retain an explicit Policy/Program/Host kind.

Call JSON replaces `"execution":"read","read":{...}` with `"classification":{"kind":"unrecorded_read","read":{...}}`. A recorded call without read identity uses `"classification":{"kind":"recorded"}`.

Consumption JSON drops `consumed`; bound JSON moves `resource`, `limit`, `observed` under `reading`. Rust and host JSON consumers must update together. No configuration or feature opt-in is needed. Reset or recreate retained bytes as required by the generated format witnesses below.
