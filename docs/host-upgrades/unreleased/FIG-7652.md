# FIG-7652: Kernel process engine state names its progress

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |

| A kernel process's engine state kept its last park (`parked`), that park's `requirements` and a `phase` of `running`, `parked` or `ended` as separate fields, so a cancelled, failed or timed-out process could still name its last park. | The state keeps one `progress`: `running` (the admitted `kernel_run` step and the park it resumes, absent before the first park) or `parked` (the run and the requirements its park recorded).
