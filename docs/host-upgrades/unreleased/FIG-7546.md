# FIG-7546: Packet execution and checkpoint closure origins

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| Saved frames identify lifted code by body site and capture names alone. | Frames also retain the exact closure creation site. Deploy matching kernel artifacts and reset checkpoints as required by the updated format witness; no opt-in is needed. | This commit, FIG-7546 | An older checkpoint fails format admission; resolving a lexical frame as a standalone function loses borrowed capture ownership. |
| Standalone frames omit their compilation origin, and lexical compilations can overwrite their source lookup entry. | Every saved frame retains its exact origin: the standalone body site or lexical creation site. Deploy matching kernel artifacts and reset prior checkpoints whose standalone frames omit the origin. No opt-in is needed. | This commit, FIG-7546 | A prior checkpoint fails semantic admission with `a frame has no compilation origin`; a standalone body cannot be recovered through a lexical variant. |
| `TemplateHeap::copy` executes a generated bulk-copy body. | Generated copies execute their source body through the shared packets. Remove implementations of `TemplateHeap::copy`; source copy-policy descriptors remain available. | This commit, FIG-7546 | A trait implementation containing `copy` fails to compile. |
| `HeapTemplate::entry` is a required `fn(&mut dyn TemplateHeap, &[Value], &[PreparedNative]) -> Option<Value>`. | It is `Option<HeapEntry>`, where `HeapEntry` aliases the same function type. Wrap externally supplied native compositions in `Some`; `None` denotes generated helpers that publish facts and execute their bodies through the packet stream, not a callable entry. No opt-in is needed. | This commit, FIG-7546 | The field has a type mismatch or an attempt to call `Option` directly fails to compile. |
| `Meters::memory` reports physical residency and a saved capacity floor. | It reports the authenticated source ledger balance, including cold holdings. No opt-in is needed. Physical residency remains available in diagnostic observations. | This commit, FIG-7546 | A host treating this value as resident memory observes different values after warming and cold reopen. |
| Explicit `plan::Forwards` literals list numeric and text native forwards. | They also carry `identity: Option<&IdentityPath>`. Use `None` or `..Default::default()` for external descriptors without a source-derived identity proof. Regenerate compiler-owned helper plans with the owning generator. Native requirements and inlined body identities are authenticated against the installed registry before this scalar path is available. | This commit, FIG-7546 | An old explicit `Forwards` literal fails to compile with a missing `identity` field. |
