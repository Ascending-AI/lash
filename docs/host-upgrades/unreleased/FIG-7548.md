# FIG-7548: Kernel callers share invocation and retain read facts

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| Model-round Read tools used recorded execution; live read rows could not be hydrated after reload | All callers save read facts with their next state or results commit. Model read plans pin presentation callbacks; the results save also retains the final model return and artifact references. `CellRecord` and `ExecResponse` carry `read_facts`; tool-call lookup includes saved reads. Render read rows by the caller and ordinal identity; `ToolReadCaller::ModelRound` identifies model reads. | This commit, FIG-7548 | Assuming every tool row has an admitted execution omits read rows from history. |
| Tool panic evidence always named an admitted call | `ToolFailureCause::ReadPanicked` and `TurnStop::ReadPanicked` carry `ReadPanic` with the tool name and message. A reader panic stops its owner. Match the new variants. | This commit, FIG-7548 | Exhaustive matches fail to compile; treating a reader panic as a catchable error allows incorrect continuation. |
| Process bound failures retained only text | `ToolFailureCause::ExecutionBound` retains resource, limit, optional observed and consumed values, function and site. `CellFailure.bound` carries the same fact, retained verbatim across takeover of a separately saved cell end. No opt-in is needed. | This commit, FIG-7548 | Hosts that parse failure text miss structured bound evidence. |
| A read's deadline used the full configured parent allowance in each layer | `RunHost::perform` and `EffectReads::perform` receive the remaining parent allowance. `EngineEffectReads::read` receives that allowance and returns a `ReadResult` containing its fact and answer. | This commit, FIG-7548 | Custom host or reader adapters fail to compile until their signatures and fact forwarding match. |
| Tool hooks could be skipped by inline reads | Any argument/result transform or check binds the call Recorded in the saved plan. Restoring the plan preserves that mode and its callback requirements. No opt-in is needed. | This commit, FIG-7548 | A Read tool can now enter its recorded provider method when hooks apply. |
