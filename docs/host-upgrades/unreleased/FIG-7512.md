# FIG-7512: Retain exact released helpers across deployments

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| The installed helper image contains only current definitions. Saved documents and runs can refuse after a helper body changes. | `helper_release()` includes authenticated historical definitions for enabled packages. Source resolution keeps current roots. Documents keep their exact helper hashes and DocumentIds. No new opt-in is required. | This commit, FIG-7512 | Unsupported exact code refuses instead of silently running a current body. |
| Helper availability refusals are `MissingHelper { function }`. | Match `HelperUnavailable { function, reason }`, with `HelperUnavailableReason::{Retired, Unknown, Corrupt}`, in document, materialization, admission, restore and carry refusals. `vm::LibraryError` is now an enum with `Library { message }` and typed `HelperUnavailable` variants. The facade exports the reason through `workflow::kernel`. `ParkedRefusal` uses `kind` as its discriminant so its reason field can carry the typed cause. | This commit, FIG-7512 | Exhaustive Rust matches and old wire decoders need updating. |
| Helper native claim debt names the installed helper-library identity. | `NodeRequirements.helpers` holds the maximum first generation for each archive lineage, plus exact hashes outside the archive grouped under their current release. A claim carries one `helper-archive:<lineage>:<generation>` floor and a `helper-outside:<release>:<hashes>` list only for unarchived code. Nodes advertise their archive generation and current/covered library identities. Claim admission compares scalar generations and release coverage. Package manifest requirements preserve feature coverage. A run waits until a node covers its reach. Nodes also advertise the historical whole-library identities their archive covers, so existing `helper-library:<id>` debts remain claimable. The checkpoint still performs its reach walk on an identity mismatch. Hosts constructing complete requirement literals must supply the field; struct defaults leave it empty. `ResolutionEntry::Resolved.requirements` shares immutable debt as `Arc<ClaimRequirements>`; constructors use `requirements.into()`. | This commit, FIG-7512 | A node missing an exact helper cannot claim the run. The unmet requirements name its missing generation or unarchived hashes. |
| Derived worker libraries are cached by authored closure alone. | Cache entries include the exact helper member identity. Internal `loader::Libraries::get_or_try` callers now pass `(closure, helper_identity, make)`. Historical native declarations retain their charge formula and bind their package/name/native_version implementation with exact callees. Only plans for present bodies are installed. Other bodies use the interpreter. | This commit, FIG-7512 | Hosts passing an incomplete frame get a native availability refusal. |

Construct `CommittedUse::Parked` with `unmet: requirements`. The worker host schema constants expose the generated protocol snapshots.

`NodeLease` shares its immutable advertisement across clones. In manual lease
literals, construct `serves` with `tokens.into()` to obtain `ServedClaims`, and
construct `capabilities` with `capabilities.into()` to obtain
`Arc<NodeCapabilities>`. Read the token slice through `serves.as_ref()` and the
prepared JSON through `serves.as_json()`. A replacement advertisement gets a new
snapshot. These lease fields have no stored or wire encoding.

The worker frame metadata also carries supported historical library identities and the authenticated first-generation index. Parent and worker binaries must use the same frame format; a mismatched binary refuses pool startup. Helper claim debt is computed in the inspection cache by exact document/run and claim-index identity, never per turn or claim. `restore_selection` remains authoritative for actual code availability. The claim-only fields stay outside authored Document requirements. The durable witnesses for the shapes below advance during landing; there is no migration or old-shape reader.

## Durable witnesses and reset action

Crate, package and semantic kernel versions stay unchanged. The format guard
allocates the effective witness values against the rebased parent. The generated
format-reset entry records those transitions. Synthetic N+1 receipt and
worker witnesses follow their normal witness. Hosts that store these formats
must reset the affected stores or retained records before opening them with
this build; no migration or old-shape reader is provided.

| Required witness | Encoded shape that changed | Hosts that store this |
| --- | --- | --- |
| `POSTGRES_SCHEMA_VERSION` | Stored `NodeRequirements`/`HelperRequirements` now carry archive generation floors and unarchived release/hash lists. Restore refusals carry `HelperUnavailable` and its typed reason. | Reset the PostgreSQL Lash store. |
| `SQLITE_CORE_SCHEMA_VERSION` | The same claim requirement and typed restore-refusal shapes in SQLite's durable records. | Reset the SQLite Lash store. |
| `RUNTIME_COMMIT_RECEIPT_SCHEMA_VERSION` | A receipt's retained restore refusal includes `HelperUnavailableReason`. Its synthetic successor follows the ordinary witness. | Reset retained runtime commit receipts with their owning store. |
| `DURABLE_READ_FIXTURE_SCHEMA_VERSION` | Captured durable-read fixtures contain the changed requirement and refusal records. | Reset and rebuild captured fixtures. |
| `WORKER_PROTOCOL_VERSION` | Live worker refusals carry the typed helper-availability cause; the pool frame carries generation metadata. Its synthetic successor follows the ordinary witness. | Restart parent and worker together; reset any retained worker frames. |
| `KERNEL_DOCUMENT_SCHEMA_VERSION` | The document's requirement schema refers to the new helper requirement representation. | Reset retained opaque document blobs and rebuild from source or typed current data. |
| `DOCUMENT_GRAMMAR_VERSION` | The document token body embeds this grammar tag. Its required equality with `KERNEL_DOCUMENT_SCHEMA_VERSION` advances the tag with that witness. | Reset retained kernel Documents and rebuild from source or typed current data. |

The grammar tag change also changes DocumentIds across those grammars. Within
the current grammar, retaining an archived helper preserves the DocumentId.
Archived eight-field FunctionDefinition identities remain unchanged.


The host replay fix stores `HelperRequirements` in shared immutable data. Hosts
constructing it use `HelperRequirements::new(archives, outside)` instead of a
struct literal. Read the maps with `archives()` and `outside()`, and mutate a
private copy with `archives_mut()` and `outside_mut()`. Earlier snapshots retain
their exact debt. Missing source changes fail at private-field construction or
field access. Its JSON and token fields keep their existing shape. There is no
new feature or configuration opt-in.
