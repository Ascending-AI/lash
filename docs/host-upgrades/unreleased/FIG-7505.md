# FIG-7505: Scope helper operation uses separately from authored imports

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `OperationUse.slot: ImportSlot`; helper and authored imports shared numeric slots. | `slot: OperationSlot`, with `Import(ImportSlot)` and `Helper(HelperOperationId)`. Preserve the entire defining Link and tagged slot for routes, reads, waits, replay and succession. An authored JSON slot changes from `0` to `{ "kind": "import", "value": 0 }`; a helper uses `{ "kind": "helper", "value": "<64 lowercase hex digits>" }`. No new opt-in. | This commit, FIG-7505 | Rust type mismatch for old slot initializers; old numeric wire slots fail decoding. |
| `Link.fills` filled authored imports and copied helper slots. | `fills` contains authored imports only. Add `helper_fills: BTreeMap<HelperOperationId, HelperFill>` with each helper declaration and its explicitly selected operation pin or deferred grant. `Namespace::fulfil` now takes a `FunctionCatalog` after `content`; `Draft::relink` takes a catalog before `namespace`. `Namespace::fulfil_existing` reselects an admitted Link's declarations. Existing provider, bounds and randomness configuration still applies per context; no ambient services or new opt-ins. | This commit, FIG-7505 | Missing `helper_fills` decoder/compiler error, missing catalog argument, or refusal of an unfilled helper operation. |
| `Requirements` contained only authored `imports` and function reach; `PreparedInstance` transported only authored `slots`. | Add `Requirements.helper_imports` for helper declaration reach, and the `PreparedInstance.helper_operations` declaration map. `Program::prepare_instances` populates it from immutable Link fills. Hosts constructing worker-start payloads must use the updated shape. No new opt-in. | This commit, FIG-7505 | Worker-start decoding rejects the missing field; a helper operation without an explicit declaration cannot execute. |
| `authoring::Imports::reserving` reserved helper slots; `library_requirements` copied imports and could return `LibraryRequirementRefusal::IncompatibleImport`. | Use `Imports::default()` for authored allocation. Helper body slots remain private; `helper_imports` projects their declaration identities, and `library_requirements` projects kernel versions. `IncompatibleImport` and `MaterializeRefusal::LibraryRequirements` are removed; unavailable helpers retain `MissingHelper`. No new opt-in. | This commit, FIG-7505 | Removed method or enum-variant compiler error. |
| Adoption refusal `from`/`to` fields, `LinkRefusal::ContractMismatch.use_`, `AdmissionRefusal::ContractMismatch.use_` and `EmbedError::ConflictingOperationRoutes.first`/`.second` held operation uses inline. | These payloads are `Box<OperationUse>` so larger exact identities do not enlarge every error result. Dereference them when comparing or collecting values. Existing feature gates remain unchanged; no new opt-in. | This commit, FIG-7505 | Rust type mismatch in constructors or destructuring consumers. |
| `execution_resolutions.slot` was SQLite `INTEGER` / PostgreSQL `BIGINT`. | The column is `TEXT`, keyed by `import:<number>` or `helper:<digest>`. Apply the current creation schema when reprovisioning pre-1.0 stores. Stored and wire formats change in place, without a version bump or migration. | This commit, FIG-7505 | PostgreSQL startup shape verification reports the old column type; old serializers or schemas cannot represent the tagged helper use. |
