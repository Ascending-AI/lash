# FIG-7516: Helper specializations share source descriptions and metering

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `TemplateMeter::mark() -> usize` and `rewind(usize)` | Return and restore `plan::ChargeMark`, including totals and recording position. Custom value-only implementations can return `ChargeMark::default()`. No opt-in is needed. | This commit, FIG-7516 | The former trait signatures fail to compile. |
| `HeapTemplate` has no copy description; `TemplateHeap` offers `concat` and `dense` | Regenerate helper plans with `kiln run //crates/lash-ext-helper-compiler:regenerate__bin`. Hand-authored heap templates set `copy: None`; custom heaps may implement `copy(args, &CopyLoop)`. The default declines. | This commit, FIG-7516 | Missing `copy` fields and removed trait methods fail to compile. |
| Symbolic native capabilities have no boolean negation variant | `SymbolicNative::Not` certifies boolean negation. Custom natives may leave it absent; any supplied capability must agree with `call`. | This commit, FIG-7516 | Exhaustive matches need the new variant; uncertified natives keep general execution. |

No stored or wire formats change. Sources: [helper interfaces](../../../crates/lash-kernel-doc/src/plan.rs), [native capabilities](../../../crates/lash-kernel-doc/src/arena/native.rs), and [copy derivation](../../../crates/lash-ext-helper-compiler/src/template/bulk.rs).
