# FIG-7701: Automatic format witnesses

## A pruned process takes its prompt snapshots

Pruning a finished process now deletes the prompt snapshots of its model calls, with their text edges, in the same transaction as its other history. Before, they stayed forever and nothing reclaimed them.
- **Host-visible change:** after the prune, `LashDiagnostics::prompt_snapshot` for one of those calls answers `None`, as every other read of a pruned process's history does.
- **Host action:** a host that needs a snapshot after a prune must read it before it prunes the process.

## No process history archive

A finished process's history (run facts, tool calls, model calls) stays as its rows until the process is pruned. The history archive that once packed it into the process row is not on this branch: the stores have no archive columns, the cleanup pass packs nothing, and every history read answers from the rows. Only the terminal event and parent-end plan stay on the process row (packing step 1).
- **Host action:** none beyond the store reset the version moves below already require.
