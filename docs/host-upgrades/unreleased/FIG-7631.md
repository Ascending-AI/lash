# FIG-7631: Native specializations carry an immediate-entry resource certificate

FIG-7694 supersedes the rest of this entry. The region ISA it introduced is
gone, and the FIG-7694 store reset covers its continuation format change.

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `lash::workflow::NativeSpecialization { immediate, resident, text_relation, text_append, .. }` has no resource certificate for its immediate entry. | It gains the public field `immediate_resources: bool`. A native that builds the struct with a full literal adds `immediate_resources: false`, or spreads `..NativeSpecialization::default()`. Set it to `true` only when every successful answer from `immediate` has exactly its immutable output as its resource obligation, with no scratch and no fresh mutable entity, in agreement with the native's `resource_contract`. No feature, configuration or policy opt-in is required. | This commit, FIG-7631 | Full struct literals fail to compile with E0063 (missing field `immediate_resources`). The bytecode core does not read the field (FIG-7694). |

Source: [native specialization](../../../crates/lash-kernel-doc/src/arena/native.rs) and [facade exports](../../../crates/lash/src/workflow.rs).
