# FIG-7499: Keep exact execution ordinals in workflow views

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `ActionView` contained a site but no exact issue ordinal. Hosts could infer the ordinal from its authored node. | Every action includes required `ordinal: u32`, including actions folded into an authored node. Read coverage and path counts using the action's ordinal. Rust constructors must supply it. No opt-in is required. | This commit, FIG-7499 | A missing Rust field fails compilation; old view JSON fails decoding with missing field `ordinal`. Inferring ordinals from authored nodes merges distinct execution counts. |
| The view's statement inventory omitted statements folded out of authored nodes. | `statements` retains every raw execution statement; `nodes` retains the folded authored presentation. Hosts addressing replay coordinates use the complete statement inventory. | This commit, FIG-7499 | A host that assumes each raw statement has its own authored node can omit coverage or replay positions. |
