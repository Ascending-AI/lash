# FIG-7529: Separate tool and cell returns from committed completions

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `TurnEvent::ToolCallCompleted` and `TraceEvent::ToolCallCompleted`, wire `tool_call_completed`, reported a live return before commit | `ToolCallReturned` / `tool_call_returned` carries provisional output. `ToolCallCompleted` / `tool_call_completed` carries the accepted round or cell outcome. Use returns for progress and completions for done state. No new opt-in is required. | This commit, FIG-7529 | Exhaustive Rust matches need the new variant; strict decoders reject `tool_call_returned`. Hosts reading only completions see output after commit. |
| `TurnEvent::CodeBlockCompleted`, wire `code_block_completed`, reported the provisional cell answer | `CodeBlockReturned` / `code_block_returned` carries provisional output. `CodeBlockCompleted` / `code_block_completed` carries the committed `CellOutcome`, after the commit consuming the cell answer. No new opt-in is required. | This commit, FIG-7529 | Exhaustive Rust matches and strict decoders must accept the new return variant; completion arrives after commit. |

The generated contracts ship as
`lash::schema::host::turn_activity::{JSON_SCHEMA, TYPESCRIPT_DECLARATION}` and
`lash::schema::host::trace_record::{JSON_SCHEMA, TYPESCRIPT_DECLARATION}`.

Both tool events retain the call identity, arguments and output payload. A worker
lost after a successful return can restore the member as Interrupted, with a
failure completion instead of a success. A failed commit publishes no completion.
OTel tool spans and flight-recorder completed outcomes use committed completions.
The same rule holds for cell returns and completions.

A live return:

```json
{"type":"tool_call_returned","call_id":"tc_910eb038af6242aa7b4b6455b0834c829a23ed3463ba9edb18723d4f72c6ae6f","name":"tools.lookup","args":{},"output":{"outcome":{"status":"success","payload":{"$lash_tool_value":"untrusted_json","value":{"ok":true}}}}}
```

After the outcome commit is accepted:

```json
{"type":"tool_call_completed","call_id":"tc_910eb038af6242aa7b4b6455b0834c829a23ed3463ba9edb18723d4f72c6ae6f","name":"tools.lookup","args":{},"output":{"outcome":{"status":"success","payload":{"$lash_tool_value":"untrusted_json","value":{"ok":true}}}}}
```

A provisional cell return:

```json
{"type":"code_block_returned","consumption":[],"language":"typescript","result":{"kind":"completed"}}
```

After the cell answer commits:

```json
{"type":"code_block_completed","consumption":[],"language":"typescript","result":{"kind":"completed"}}
```
