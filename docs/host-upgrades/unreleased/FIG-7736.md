| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| The SQL process creation JSON included `id` and `start_key`. The event header JSON included `process_id`, `sequence`, `event_type` and `invocation`. | The registry builds records from the indexed process ID and start key. The event header stores `occurred_at` and optional `replay_attribution`. The registry builds the event and its invocation from the SQL process ID, kind, sequence and replay key. | This commit, FIG-7736 | This build refuses catalogs stamped with the earlier SQLite or PostgreSQL component version. |
| Graph node inserts supplied `body_bytes` alongside `node_json`. | Both stores generate `body_bytes` from the UTF-8 octet length of `node_json`. Provision a compatible catalog before opening with this build. SQL fixture writers must omit the generated column. | This commit, FIG-7736 | An INSERT or UPDATE that supplies `body_bytes` fails because it is a generated column. |
