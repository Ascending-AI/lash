# FIG-7549: Shared turn progress and terminal tool stops

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| Standard tool steps never spent `NoProgressBudget`, even when every tool failed. | A Standard step with no successful tool execution spends one attempt; any successful execution resets the consecutive count. Code mode counts successful cells, including caught tool failures. Both persist the meter across checkpoint restore and steering. No new opt-in. | This commit, FIG-7549 | Repeated failing or refused Standard tools now stop at the configured no-progress bound instead of running to the turn bound. |
| Code mode ran `BeforeCompletion` hooks for terminal tool failures. | Hard stops finish immediately in both protocols, after recording execution. Declared completions still pass through `BeforeCompletion` and may be superseded by arriving input. No new opt-in. | This commit, FIG-7549 | Completion hooks no longer replace a code-mode tool's intended `ToolError`. |
