# FIG-7485: Optional resident text join certificate

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `NativeFunction` had no resident text join certificate. | `NativeFunction::prepare_text_join() -> bool` defaults to `false`. No host action is required. A native may opt in only when its call joins a list of texts with a text separator. The VM retains its declared charge formula and memory reservation. | This commit, FIG-7485 | Existing implementations keep the general native call path. An incorrect opt-in can produce a result that disagrees with the native implementation. |
| `Objects` exposed one mutable body at a time. | Optional `Objects::get_disjoint_mut(first, second)` borrows two distinct bodies and rejects aliases or stale handles. No host action is required. | This commit, FIG-7485 | An alias or stale handle returns `None` before either body changes. |

Source: [native function contract](../../../crates/lash-kernel-doc/src/arena/native.rs).
The optional body borrow is in [Objects](../../../crates/lash-kernel-doc/src/arena.rs).
