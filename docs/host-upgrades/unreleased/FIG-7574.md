# FIG-7574: Host operations carry identities instead of actor contexts

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `core.effect_host()`, `session.effect_host()`, `lash::runtime::ActorContext` | Removed. External ingress constructs `OperationId::new(request_id)` and retains it for every retry. Lash binds the operation to its own core. | This commit, FIG-7574 | Missing method or import |
| `processes.start(request, actor)` | `processes.start(operation_id, request)`. The operation identity is the start key, including after reopening. | This commit, FIG-7574 | Incorrect argument type |

All eight example patterns are external ingress, kind 1:

| Original site | Old call | New call |
| --- | --- | --- |
| `agent-workbench/e2e_receiver.rs:76` | `register_receiver(core, session, core.effect_host())` | `register_receiver(core, session, OperationId::new(format!("h2-receiver:{session}")))` |
| `agent-workbench/e2e_receiver.rs:106` | `start_sleeper(core, session, millis, core.effect_host())` | `start_sleeper(core, session, millis, OperationId::new(format!("h2-sleeper:{session}")))` |

| `agent-workbench/main_sections/host_ingress.rs:21` | Scope an actor as `workbench-process-cancel:{operation_id}` and call `cancel(process, actor)` | `cancel(OperationId::new(format!("workbench-process-cancel:{operation_id}")), process)` |
| `e2e-consumer/workflow.rs:663` | Put `request.key` in the request and pass `host.core.effect_host()` | `start(OperationId::new(request.key), request)` |
| `workflow-graph-roundtrip/host_guide.rs:184` | Put `key` in the request and pass `core.effect_host()` | `start(OperationId::new(key), request)` |
| `workflow-graph-roundtrip/runtime.rs:1070` | `CommandClient::start(request)` passes `self.0.effect_host()` | `CommandClient::start(OperationId::new(key), request)` forwards the ingress identity |

A request's old host key is superseded by the explicit operation identity.
`OperationId::mint()` creates a fresh operation; retain that value for retries.
Conformance fixtures use the internal conformance package's actor type.
