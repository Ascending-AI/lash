# FIG-7563: Read nested tool progress from JSON

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| Nested progress records such as `{"progress":0.5,"total":1.0}` could be misread when serde_json arbitrary precision was enabled. | The reader accepts finite progress and finite, null or missing total. Ordinary numeric JSON is unchanged; no host code or API change is needed. | This commit, FIG-7563 | PostgreSQL live replay reported `CorruptPayload` with `invalid type: map, expected f64` for a valid progress fact. |
