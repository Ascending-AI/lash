# FIG-7587: A tool completion names its call and committed outcome

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `TurnEvent::ToolCallCompleted`, wire `tool_call_completed`, repeated the call's `args` and `output` | It carries the call identity, `name`, `duration_ms`, `graph_key` and `commit`: `{"kind":"returned"}` when the commit holds the output the call's `ToolCallReturned` carried, or `{"kind":"output","output":…}` with the committed output (no live return carried it, Interrupted on recovery, or a successor's fold replaced it). Read arguments from `ToolCallStarted` / `ToolCallReturned`; `ToolCallCommit::output` resolves the committed output given the call's returned one. | This commit, FIG-7587 | Rust matches on `args`/`output` no longer compile; strict decoders reject `tool_call_completed` without `commit`. |

{"type":"tool_call_completed","call_id":"tc_910eb038af6242aa7b4b6455b0834c829a23ed3463ba9edb18723d4f72c6ae6f","name":"tools.lookup","commit":{"kind":"returned"}}
