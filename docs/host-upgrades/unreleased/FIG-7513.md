A construction bailout now resumes at the first unpaid charge region, including
adjacent split heads. Previously a reference layout could skip one expression
charge before a later memory refusal. The recorded 38,912-byte Python case now
refuses at charge 579 in both layouts, rather than 579 and 578. This restores a
missing expression charge; operation formulas and the canonical charge schedule
are unchanged.
No opt-in or store reset is required.

This is a partial repair. FIG-7513 remains open: reference helper temporaries,
cold frame and value accounting, saved capacity floors, and the complete
refusal/restore law still prevent executor- and checkpoint-independent memory
bounds.

Source: [terminal cleanup](../../../crates/lash-kernel-vm/src/machine/ops.rs) and [heap and frame records](../../../crates/lash-kernel-state/src/paged/root.rs).

The heap now publishes its current logical ownership in `HeapRoot.logical`.
`PagedHeap::logical_ledger()` returns the shared runtime authority;
`logical_balance()` and `LedgerRoot::balance()` read its current components.
Seal/open persist and restore those components independently of physical
capacity. A residency warm authenticates an existing logical fact without
creating another occurrence or body claim. This landing supplies that private
VM interface; guest refusal and public meters still use the prior admission
path until the remaining FIG-7513 cutover.
