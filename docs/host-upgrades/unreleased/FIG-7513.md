# FIG-7513: Native host-storage failures are typed

FIG-7694 supersedes the rest of this entry. The bytecode core replaced the
executor, memory accounting and checkpoint shapes it described, and the
FIG-7694 store reset covers every format change it made.

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `workflow::NativeError` has no typed host-storage failure variant. | `workflow::NativeError::Host(HeapFault)` preserves host staging exhaustion from atomic native batch preparation. Native implementers and exhaustive matchers must handle it as infrastructure failure; it is not a guest memory bound or catchable guest error. No configuration opt-in or store reset is required for this enum addition. | This commit, FIG-7513 | An exhaustive `NativeError` match fails to compile until it handles `Host`; staging exhaustion must retain its typed `HeapFault`. |
