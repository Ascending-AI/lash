# Queued-turn commit delivery

No host action is required. Session observation now checks the durable head
when the backend reports a session change and recovers retained commits from
replay if the live subscription missed their notification. Adjacent queued
turns remain ordered and are delivered once, without waiting for a timer.

The feed uses the backend's existing change listener, including PostgreSQL
notifications across processes. Multi-process hosts still configure a shared
live replay store. When replay no longer retains a continuation, the feed
reports a gap with the authoritative durable snapshot.
