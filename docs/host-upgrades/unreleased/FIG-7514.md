# FIG-7514: Explain unprintable source and keep canvas insertions before implicit returns

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `PrintError::Unprintable { site }` and the worker's `Response::Unprintable { site }` | Both carry `reason: UnprintableReason`. Match the reason or use `..` when only the site matters. Rebuild parent and worker together. No new opt-in. | This commit, FIG-7514 | Old exhaustive patterns fail to compile; an old worker response cannot decode as the new response. |
| `GENERATED_SOURCE_UNPRINTABLE` messages name only a site | The same code now names the construct and its missing authored form. `lash.source.print` records `refusal.construct`, `refusal.reason`, and `refusal.site` when debug tracing is collected. No additional detail policy is required. | This commit, FIG-7514 | A host that parses message prose should switch to the typed reason. |
| `Conventions` declared argument, reply and iteration forms | Declare `returns: Returns` `bindings: BindingScope`, `inverse: Inverse` and `source_only` as well. Lash supplies it through `workflow::edit::CONVENTIONS`; custom conventions choose their implicit value, async return policy and local binding scope. `EditDiagnosticKind::Unprintable { reason }` reports a damaged source form atomically. | This commit, FIG-7514 | Custom struct literals need the new field; hosts decoding edit refusals must accept the new `unprintable` variant. |
| A canvas end position could append work after a lowering-owned implicit return | End insertions and moves precede the return. Previously saved malformed documents remain explicitly unprintable and name their invalid implicit return. | This commit, FIG-7514 | Old drafts require a source edit or a new canvas insertion from the original printable document. |

Source editing now verifies the declared inverse before `Draft::apply` publishes its candidate. An `Inverse::Checked` callback returns the ordinary-lowered document. Admission accepts only the printer's existing private-name, local-function-name and import-slot equivalence, publishes that canonical document, and remaps correspondence to its function identities. Executable tree shapes must stay identical. `workflow::edit::CONVENTIONS` installs local verifiers when the host enables `typescript` and/or `python`. A parser-free host can still edit kernel documents; source editing needs an installed `Inverse::Checked` verifier or the matching local dialect feature. Without it, admission returns typed `InverseUnavailable` and changes nothing. Raw helper-owned `typescript.sleep` calls require the authored sleep construct and are refused explicitly. No runtime worker parser is forced into a parser-free host.

Source: [print errors](../../../crates/lash-kernel-dialect/src/imperative.rs), [worker print service](../../../crates/lash-vm-client/src/service/source.rs), [canvas positions](../../../crates/lash-kernel-edit/src/apply.rs).

Fresh imports also cross zero-edit admission. Callable tokens and statement-valued conditionals recover at their original expression positions, and canvas insertions follow lowering-owned scope predeclarations. These fixes retain the inverse verifier and exact executable-shape comparison.
