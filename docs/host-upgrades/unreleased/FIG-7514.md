Source editing now verifies the declared inverse before `Draft::apply` publishes its candidate. An `Inverse::Checked` callback returns the ordinary-lowered document. Admission accepts only the printer's existing private-name, local-function-name and import-slot equivalence, publishes that canonical document, and remaps correspondence to its function identities. Executable tree shapes must stay identical. `workflow::edit::CONVENTIONS` installs local verifiers when the host enables `typescript` and/or `python`. A parser-free host can still edit kernel documents; source editing needs an installed `Inverse::Checked` verifier or the matching local dialect feature. Without it, admission returns typed `InverseUnavailable` and changes nothing. Raw helper-owned `typescript.sleep` calls require the authored sleep construct and are refused explicitly. No runtime worker parser is forced into a parser-free host.

Source: [print errors](../../../crates/lash-kernel-dialect/src/imperative.rs), [worker print service](../../../crates/lash-vm-client/src/service/source.rs), [canvas positions](../../../crates/lash-kernel-edit/src/apply.rs).

Fresh imports also cross zero-edit admission. Callable tokens and statement-valued conditionals recover at their original expression positions, and canvas insertions follow lowering-owned scope predeclarations. These fixes retain the inverse verifier and exact executable-shape comparison.

Authored waits and standalone calls can be removed as canvas steps. TypeScript's sleep result wrapper is declared by `DiscardResult`, shared by lowering, recovery and structural editing. Custom `Conventions` literals now also supply `discard_result` (`None` unless their source action discards a result into a fixed value) and `separable_step` (a predicate protecting statements owned by larger source constructs). Python protects comprehension element computation with its shared comprehension declaration. Raw sleep insertion remains refused. Unsafe deletions keep typed `NonSeparableStep` or `EscapingBinding` diagnostics; the former's message describes surrounding computation and control flow rather than requiring a perform.

Boundary recognition also shares `BoundaryOperand::Forwarder` with recovery: the default operand is absent, and an optional factory must construct values without executing actions. Authoring helper resolution uses the document's pinned release and local definitions, including forwarding factories, rather than an ambiguous ambient helper role.

Deleting or replacing a boundary removes its abandoned forwarding factories and their private callable definitions. All other guest declarations remain retained. `WorkflowEnvironment::checker()` now resolves new authoring helpers against the worker library's source resolver roots, while exact definition lookup still uses the full registry. This keeps new loop wrappers constructible even when retained releases make global helper names ambiguous.
