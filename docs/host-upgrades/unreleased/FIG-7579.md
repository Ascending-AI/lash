| `lash-sdk-worker-VERSION-linux-x86_64.tar.gz` bundled `sdk/` and a source hash inventory | Choose `lash-sdk-worker-VERSION-linux-x86_64-python-typescript.tar.gz`, `lash-sdk-worker-VERSION-linux-x86_64-typescript.tar.gz` or `lash-sdk-worker-VERSION-linux-x86_64-python.tar.gz`. Each holds only stripped `bin/lash-vm-worker`, `THIRD-PARTY-NOTICES` and `manifest.json`, with an external `.sha256` sidecar. Get sources from Cargo or GitHub's source archive.
