# FIG-7510: Native specializations describe their own capabilities

| Old contract | New contract / host action | Commit and ticket | Missed-change diagnostic or symptom |
| --- | --- | --- | --- |
| `NativeFunction::prepare_text_relation() -> Option<ScalarOp>` | Override `specialization() -> NativeSpecialization`, set `text_relation`, and retain `immediate: self.prepare()` when supplying an immediate entry. No feature or configuration opt-in is required. | This commit, FIG-7510 | The removed trait method fails to compile. |
| `NativeFunction::prepare_text_join() -> bool` | Set `text_join` in `NativeFunction::specialization()`. A wrapper should preserve its inner native's other capabilities. | This commit, FIG-7510 | The removed trait method fails to compile. |
| `NativeFunction::prepare_collection_length() -> Option<ValueKind>` | Set `resident: Some(ResidentRead::Length(collection))` in `specialization()` for the certified collection kind. | This commit, FIG-7510 | The removed trait method fails to compile. |
| Resident native reads and text append were selected by library names | A custom native may supply `resident` or `text_append` in its own `NativeSpecialization`. Leaving these absent keeps the general native call. Every supplied capability must agree with `call`. | This commit, FIG-7510 | Execution remains correct through the general call; an uncertified custom native receives fewer shortcuts. |
| `HeapTemplate::element: Option<Element>` | Regenerate helper plans with `kiln run //crates/lash-ext-helper-compiler:regenerate__bin`. The field is now `Option<ElementPath>`, carrying its operation, depth, temporary holdings and required native facts. No stored or wire format changes. | This commit, FIG-7510 | Old hand-authored element annotations fail to compile. |
