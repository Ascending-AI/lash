# Tests to remake against the replacement kernel

FIG-6689 removes tests outside kernel crates that depend on the outgoing engine. These are specifications for replacement laws, not claims that the removed performance or layout checks still run. Semantic laws using only outer seams remain in place. FIG-6690 records the kernel-internal removals in the same ledger, grouped separately by crate and cluster.

The outer seams include the embedding API, semantic session/park readers, the page transport port and the native extension interface. Layouts, stream verification, work codes, tree/payload traversal and concrete census admission are implementation details. Memory refusal is conservative under the replacement engine: do not reinstate equal exact refusal thresholds across plans.

A **semantic gap** below marks a deleted value, error, effect, charge or host-observation oracle for which no surviving law was identified that pins the same workload and condition. Broader semantic suites can remain green without proving that exact clause. These are deliberate gaps accepted by the owner on 2026-10-17; this change adds no replacement laws. Remake them against the new engine using the input and prior oracle in the same row. Superseded exact-memory thresholds and physical layout/performance expectations are not replacement semantic requirements.

These tests pinned the retired execution representation. Each row records the old input and oracle and names the semantic property to remake through the new engine. A remake is pending, not a claim that a new test was added here. Existing semantic laws and stored-format vectors remain in place.

Kernel PLAN-INDEP and CONT-EXACT remain semantic oracles. Their existing layout choice stays confined to the kernel test embedder (`Setup.layout`, which prepares a `Program`); no new production knob or layout contract is introduced. Numeric/list plan laws retain results, errors, effects, charge and canonical continuation comparisons after their private counters are removed.

Admission and exact-memory laws owned by FIG-6672 (`rl-rewiden`) remain for that lane, including its frame-register, pin-precision and transfer-root tests.

Owner ruling, 2026-10-17: these are deliberate kernel-decoupling removals, including mechanics coverage introduced by FIG-6681, FIG-6613, FIG-6614, FIG-6566, FIG-6500, FIG-6456, FIG-6425, FIG-6318 and FIG-6369. Do not restore these tests or add replacements against the retiring internals. Remakes belong against the new engine. Rows marked **semantic gap** identify a specific old input/oracle for which the audit did not identify a surviving outer-seam counterpart; adjacent surviving laws are named without claiming they cover the whole gap.

The kernel retained-law audit below contains all 45 laws selected for the original proof. Of these, 36 actually lost mechanics assertions (including shared Trace equality); nine were conservatively selected but use independent helpers and lost no assertion. All 45 executed once and passed. The earlier report counted all 45 as stripped; this audit corrects that count without changing any Rust test or rerunning it.
