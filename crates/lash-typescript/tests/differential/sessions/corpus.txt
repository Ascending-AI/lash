session top-level-declarations
about let, const, var and function declarations at a cell's top level are session globals
probe a b c d
deviation closure-boundary
cell
let a = 1;
const b = [2, 3];
var c = { three: 3 };
function d() { return 4; }
console.log(a, b, c, d());
cell
console.log(a + b.length + c.three);
end

session loop-binders
about for...in, classic for and while-block bindings end with their loop
probe record key keys i count inner
cell
const record = { x: 1, y: 2 };
const keys = [];
for (const key in record) {
  keys.push(key);
}
let count = 0;
for (let i = 0; i < 3; i++) {
  count = count + i;
}
while (count < 5) {
  const inner = count;
  count = inner + 1;
}
console.log(keys, count);
end

session shadowing
about a block shadow neither leaks nor overwrites the session global it shadows

}

  const shade = "block";
  console.log(shade);

  let shade = "arm";

end
