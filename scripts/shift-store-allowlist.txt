# Shift store-call allowlist (FIG-3824). One entry per (file, normalized line
# text) pair, in the rule-5 format:
#
#   path  |  <normalized line text>  |  <occurrence count>  # <tag>
#
# Every direct persistence-trait call in the session shift is pinned. The tag
# says where it runs: RECORDED is a call inside a recorded step's body (the
# step's output is what a replay reads); FENCED is a live revalidation that
# can only stop a stale shift before another turn effect (ADR 0105 §2);
# a ticket id is a call the shift still makes outside any recorded step;
# RECONCILE is the reconcile sweep, which schedules shifts and decides
# nothing inside one. A hit fails when its (file, text) is unlisted or occurs
# more times than the count; a count above the current occurrences is stale
# and fails. The occurrences not tagged RECORDED may only shrink
# (scripts/shift-store-allowlist.count caps them).
