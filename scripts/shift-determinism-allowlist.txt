# Shift determinism allowlist (FIG-3672 inventory). One entry per
# (file, normalized line text) pair:
#
#   path  |  <normalized line text>  |  <occurrence count>  # <tag>
#
# The line text is the offending source line trimmed, with internal whitespace
# collapsed to single spaces; the `  |  ` / `  # ` separators use a double
# space, which normalized text can never contain. Keys ignore line numbers,
# so edits that move or reindent a pinned site stay pinned. A hit fails when
# its (file, text) is unlisted or occurs more times than the count; a count
# that exceeds the current occurrences is stale and fails, so fixes must
# delete or decrement entries. The tag's first word is the class: a FIG-3672
# inventory id for a site the inventory still counts (UNMAPPED = the line lint
# flags code the §1 tables do not cite by line; OBS = a §1 observation-only
# site), RECORDED for a use whose result a journaled step records, or BENIGN
# for one that provably cannot affect replay (test-only or observational) --
# the rest of the tag is the site's one-line reason. Only the inventory-id
# occurrences count against scripts/shift-determinism-allowlist.count.
